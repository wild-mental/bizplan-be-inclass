## 1) 북극성 지표(NSM) 제안

### [북극성지표 v1] 장기 성공을 나타내는 단 하나의 지표

**NSM v1: ‘제출 가능(ready-to-submit) 산출물’ 완성 프로젝트 수 (주간/월간)**

- **정의**: 사용자가 “제출 가능한 수준”에 도달한 프로젝트의 수  
  - 제품적으로는 “초안 생성 → 품질 점검(체크리스트/심사) → 수정 루프 → 내보내기”가 완료된 상태
  - PRD/SRS에서 말하는 “제출 가능 품질”의 도달을 측정하는 지표
- **선택 이유(논리)**:
  - **가치의 본질을 직접 측정**: 사용자에게 가장 중요한 결과는 “합격률”이지만, MVP 단계에서 합격 여부는 외생 변수(심사·운·타이밍)의 영향이 큼. 반면 “제출 가능 산출물 완성”은 제품이 제공하는 핵심 가치(시간 단축, 논리 정합성, 양식 준수)를 **직접 반영**함.
  - **PRD의 North Star(TTV)와 정합**: TTV를 줄이는 궁극 목적은 ‘제출 가능한 문서’를 빠르게 만드는 것. 결국 장기적으로는 **제출 가능한 산출물의 ‘완성량’**이 성장과 수익을 견인함.
  - **반복 사용/업셀의 기반**: 제출 가능한 산출물을 만든 사용자는 “다음 과제/다음 공고/투자유치 문서”로 재사용할 가능성이 높아, 리텐션·매출과 연결됨.

**NSM v1 달성을 위한 선행 지표(Input Metric) 3가지**

- **Input 1: ‘첫 아하 모먼트’ 도달률(Activation Rate)**  
  - 정의 예시: 가입/진입 후 1세션 내 “초안 생성” 또는 “AI 심사 데모 완료”에 도달한 비율
- **Input 2: ‘수정 루프’ 반복 횟수(품질 향상 행동량)**  
  - 정의 예시: 사용자 1명당 “AI 심사/체크리스트 → 수정 → 재평가” 반복 횟수 (특히 Pro 플랜의 80점 미달 재작성 루프와 강결합)
- **Input 3: ‘내보내기(Export) 시도’ 수**  
  - 정의 예시: 프로젝트당 HWP/PDF/DOCX 내보내기 클릭 수 (가치 실현의 마지막 관문)

### [북극성지표 v2] 단기 런칭 성공을 나타내는 단 하나의 지표 (빠른 호흡)

**NSM v2: 주간 ‘무료 데모 완료’ 수 (작성 데모 + AI 심사 데모 합산)**

- **정의**: 랜딩에서 강조하는 “무료로 AI 심사 받아보기 / 무료 데모 바로가기(작성/심사)”를 실제로 끝까지 완료한 횟수
- **선택 이유(논리)**:
  - **시장 검증에 최적**: MVP 런칭 초기에 중요한 건 “관심(방문)”이 아니라 “아하 경험(완료)”의 발생량.  
    랜딩의 약속(10분/무료/즉시 결과)을 실제로 경험한 사람 수가 늘어야 다음 단계(회원가입·사전등록·유료 전환)가 설득됨.
  - **퍼널 병목을 빠르게 드러냄**: 데모 완료율이 낮다면 “질문/입력 난이도”, “결과의 임팩트”, “로딩/대기시간”, “신뢰 메시지” 중 어디가 문제인지 바로 실험 가능.

**NSM v2 달성을 위한 선행 지표(Input Metric) 3가지 (완벽히 제어 가능한 ‘행동량’ 중심)**

- **Input 1: 주간 ‘고객 획득 실험’ 실행 수**  
  - 예: 광고 크리에이티브 A/B 3개 제작·집행, 커뮤니티 글 5개 발행, 파트너 뉴스레터 2건 발송 등 (실행 건수 자체는 내부가 100% 통제)
- **Input 2: 주간 ‘퍼널 개선 실험’ 실행 수**  
  - 예: 데모 첫 화면 카피 A/B, 입력 폼 단계 축소, 결과 화면의 “다음 행동(사전등록/저장)” CTA 실험 등
- **Input 3: 주간 ‘세일즈/제휴 아웃리치’ 시도 수**  
  - 예: 창업센터/대학/액셀러레이터/소상공인 단체 대상 콜드메일·DM·전화 시도 횟수

> 핵심 원칙: NSM v2는 “완료”라는 결과 지표지만, **Input 3개는 실행량**(내부 통제 가능)으로 두어 “이번 주 우리가 뭘 했는가”가 바로 보이게 설계합니다.

## 2) AARRR 퍼널 분석

### 2.1 일반적인 AARRR (제품 구조 기준)

#### Acquisition (획득): 고객이 우리를 처음 발견하는 채널/방법

- **검색 기반(의도 강함)**: “예비창업패키지 사업계획서”, “초기창업패키지”, “정책자금 사업계획서”, “TAM SAM SOM”, “사업계획서 양식(HWP/PDF)” 키워드 SEO/콘텐츠
- **커뮤니티 기반(고밀도)**: 예창패/초창패 준비 카페·오픈채팅·네이버카페, 창업 관련 디스코드/슬랙, 소상공인 커뮤니티
- **파트너 기반(신뢰 전이)**: 대학 창업센터, 창업진흥원·지자체 창업 프로그램 운영기관, 액셀러레이터, 로컬 상공회의소/소진공 네트워크
- **퍼포먼스 광고(스케일)**: “마감 임박/합격/지원금/사업계획서” 문제-상황 기반 크리에이티브

#### Activation (활성화): “아하!” 모먼트의 첫 행동

**아하 모먼트(권장 정의)**: “내 상황을 입력하니 10분 내에 ‘심사위원 관점’ 피드백/초안이 나오고, 내가 뭘 고쳐야 하는지 바로 보인다.”

- **첫 핵심 행동**: 무료 데모에서 “AI 심사 완료” 또는 “초안 생성 완료”
- **강화 요소**: 결과 화면에서 “6개 영역 점수/피드백” + “다음 행동(수정 루프/저장/내보내기)”가 한 번에 제시될 때 활성화가 강해짐

#### Retention (유지): 다시 돌아오게 만드는 재방문 요소

- **마감/일정 기반 리마인더**: “접수 마감 D-7/D-3/D-1 체크리스트” 푸시/메일
- **수정 루프 기반**: “점수 80점 미만 자동 반려 → 보완 → 재심사”를 게임처럼 반복하게 만드는 구조(특히 Pro)
- **버전 관리/히스토리**: “수정 전·후 비교”, “피드백 반영률” 같은 진척 지표 제공
- **다음 문서로 확장**: 정부과제 → 정책자금 → IR Deck(시장성/경제성)으로 자연스럽게 이어지는 재사용 경로

#### Revenue (수익): 수익이 발생하는 지점

- **유료 전환 트리거(명확)**:
  - “점수 리포트/통합 피드백(플러스)”
  - “80점 미달 재작성 루프/무제한 수정(프로)”
  - “도메인 전문가 매칭/1:1 컨설팅(프리미엄)”
- **가격 구조(현재 랜딩 기반)**: 시즌형 패키지(정부지원 시즌/상반기 등) + 사전등록 할인코드(결제는 오픈 후)

#### Referral (추천): 자발적 바이럴 트리거

- **공유 가능한 결과물**: “6개 영역 점수 카드”, “Top 3 개선 포인트”, “내 계획의 취약점 요약”을 이미지/링크로 공유
- **합격/통과 스토리**: “마감 3일 전 10분 초안 → 합격” 같은 스토리형 UGC(커뮤니티에서 잘 퍼짐)
- **팀/멘토 협업**: “멘토에게 링크로 보내 피드백 받기”가 자연스럽게 추천으로 이어짐

### 2.2 고객 여정지도 기반 AARRR (페르소나/상황별)

랜딩과 PRD의 페르소나를 “상황(트리거)→첫 가치→반복 행동→결제 이유”로 재정의해, 채널/메시지/아하를 분리합니다.

#### Persona A: 김예비(예비/초기창업패키지, 마감 임박)

- **Acquisition**: “마감 D-7/D-3” 문구의 커뮤니티 게시글, 검색 키워드(예창패 양식/사업계획서 예시/재무 막막)
- **Activation(아하)**: “질문에 답만 했는데 10분 안에 ‘제출 형식 초안’이 나온다(양식/문장/목차 스트레스 해소)”
- **Retention**: “필수 항목 누락 방지”, “체크리스트 10개+”, “재무-서술 정합성 경고”로 수정 루프 유도
- **Revenue**: “점수/통합 피드백”으로 서류 통과 확률을 올리는 패키지 구매(플러스/프로)
- **Referral**: 같은 기수 준비생끼리 “이거 돌려보면 허점이 바로 나옴” 공유

#### Persona B: 박사장(소상공인, 대출 심사/상권·추정 손익)

- **Acquisition**: 지역 상공인 커뮤니티, 소상공인 정책자금 카페, 오프라인 교육(소진공/상공회의소) 연계
- **Activation(아하)**: “숫자 울렁증인데도 매출·지출만 넣으면 추정 손익(경제성)과 설명 문장이 같이 나온다”
- **Retention**: “은행 질의응답 대비 체크”, “상권/경쟁 근거 보강 템플릿”, “내 지표(매출/마진) 변화 시 자동 업데이트”
- **Revenue**: “은행 제출용 패키지(경제성+실현가능성 중심)”로 업셀
- **Referral**: 지인 소상공인에게 “은행이 요구하는 문서 형태로 바로 나온다”로 추천

#### Persona C: 최민혁(재창업가/엔지니어, PMF 검증 집착)

- **Acquisition**: 개발자 커뮤니티, 테크 창업 커뮤니티, “PMF/유닛이코노믹스/LTV CAC” 콘텐츠
- **Activation(아하)**: “6개 관점이 동시에 팩트 기반으로 반박/검증하고, 다음 실험(가설/지표)을 제안한다”
- **Retention**: “가설→실험→지표→재무” 연결 보드(후속), 현재는 “재평가 루프”로 유지
- **Revenue**: “무제한 수정/재심사(프로)” + “도메인 전문가 1:1(프리미엄)”로 전환
- **Referral**: 팀/공동창업자에게 결과 링크 공유(내부 설득) → 자연스러운 확산

#### Persona D: 한서윤(투자유치 CEO, TAM-SAM-SOM/IR 방어)

- **Acquisition**: 액셀러레이터/VC/데모데이 네트워크, IR/피치덱 템플릿 콘텐츠, “TAM SAM SOM 근거” 검색
- **Activation(아하)**: “시장성·경제성 관점에서 ‘방어 가능한 근거’가 생긴다(질문 대응이 쉬워짐)”
- **Retention**: “질문 리스트/예상 Q&A”, “수치 근거 업데이트” 반복
- **Revenue**: “프리미엄(전문가 매칭+컨설팅)”로 높은 단가 전환
- **Referral**: 같은 배치/동문 창업자에게 “IR Q&A 대비에 효과”로 추천

## (부록) MVP 그로스 실행 원칙 (짧게)

- **MVP에서 이길 포지셔닝**: “생성기”가 아니라 **‘심사위원단(검증)’**.  
  사용자 의사결정은 “그럴듯함”보다 “탈락 리스크 제거”에 더 큰 값을 둡니다.
- **가장 강한 훅(Hook)**: “10분/무료/즉시 결과” + “6개 영역 점수/피드백”  
  → 데모 완료를 NSM v2로 삼는 이유입니다.
- **리텐션의 본질**: “마감이라는 타임박스” + “점수라는 목표” + “반복 루프”  
  → Pro의 ‘80점 미달 재작성 루프’는 성장 장치로 설계 가치가 큽니다.
